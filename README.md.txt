# 📊 Excel Analítica Pro

Repositorio dedicado a proyectos de **análisis de datos e inteligencia de negocios con Excel avanzado**. Aquí encontrarás soluciones completas que abarcan desde la extracción y limpieza de datos hasta el modelado y la visualización ejecutiva.

---

## 🚀 ¿Qué encontrarás en este proyecto?

* **Limpieza y transformación de datos (ETL):** Automatización de flujos de trabajo y depuración de bases de datos crudos utilizando **Power Query**.
* **Modelado de datos y métricas:** Creación de modelos relacionales eficientes, tablas de hechos/dimensiones y medidas calculadas con **DAX** en **Power Pivot**.
* **Visualización y Dashboards:** Diseño de gráficos dinámicos, indicadores clave de rendimiento (KPIs) y reportes interactivos enfocados en la toma de decisiones.

---

## 🛠️ Herramientas y tecnologías

* **Microsoft Excel** (Funciones avanzadas, Tablas Dinámicas)
* **Power Query** (Lenguaje M)
* **Power Pivot** (Modelado de datos y fórmulas DAX)

---

## 📌 Cómo explorar los proyectos

1. Descarga el archivo `.xlsx` deseado desde la carpeta **`proyectos/`**.
2. Abre el archivo en Microsoft Excel (se recomienda versión 2019, 2021 o Microsoft 365 para compatibilidad total con Power Pivot y Power Query).
3. Habilita el contenido y actualiza las consultas en la pestaña **Datos > Actualizar todo** si deseas probar la conexión con los archivos de origen.
